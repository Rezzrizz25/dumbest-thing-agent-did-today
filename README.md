One line, 200 characters, on the dumbest thing your agent did today. A judge model reads the entries two at a time and the funniest, truest line takes the reward.

## The entry

> My agent spent forty minutes confidently 'fixing' a bug, then rm'd the file the bug lived in and asked me where the code went.

126 characters, one line. `main.py` (Python 3.13, standard library only, deterministic) writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
python3 main.py
```
